# GameXWIN Aether Android Launcher

Real Android HOME launcher prototype for Bliss OS / Android 13. It lists and launches installed apps, searches app labels and opens Android Wi-Fi, Bluetooth and system Settings. No privileged permissions, root modifications, or system app removal.

GitHub Actions workflow builds a debug APK. Install the APK on a test Android device and select it as the default Home app. This is a functional launcher, **not** the complete mockup: it does not yet implement a custom control center, full desktop taskbar, Wine integration, or system boot animation replacement. This APK is not embedded in the Bliss ISO by the ISO workflow.
