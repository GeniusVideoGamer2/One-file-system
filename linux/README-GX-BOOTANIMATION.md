# GameXWIN Aether boot animation

Animated Plymouth script theme with dark violet gradient, pulsing GX logo and five orbiting dots. Activated by the live-build chroot hook; `quiet splash` is already in the kernel command line. It is not a video, GIF, or a static boot splash.

**Status:** committed source only; not yet boot-tested. Plymouth text rendering and theme activation must be validated in a real ISO/VM. Firmware/GRUB screens appear before Plymouth and are not controlled by this theme.
