# GX Apps

GX Apps is a working Python Tkinter application hub for GameXWIN XFCE. It launches existing system tools for files, settings, software management and terminal, and displays OS information. It is **not yet** a replacement file manager, package store, settings daemon, or terminal emulator. The package list must include `python3-tk` and `synaptic`. Run locally with `python3 linux/overlay/usr/local/bin/gx-apps` on a Linux desktop with Tk installed.
