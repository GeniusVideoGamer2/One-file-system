# GameXWIN Aether real desktop

This branch builds a Debian 13 (Trixie) XFCE live ISO. Desktop components: XFCE window manager and top panel, Thunar file manager, Plank dock, dark GTK theme, Papirus icons, and an original purple GX mountain wallpaper. Wine is included for compatible Windows programs. Waydroid is not installed or enabled by default.

The original user-provided screenshot is a **visual reference**, not a wallpaper redistributed from it. The wallpaper in this repository is original SVG art. The desktop setup runs once at XFCE login. Panel and wallpaper details may need adjustment on different hardware.

To build, use the GitHub Actions workflow GameXWIN Linux Aether ISO on the `gamexwin-os-1.0` branch. Only treat the ISO as ready after a successful workflow and boot test.
